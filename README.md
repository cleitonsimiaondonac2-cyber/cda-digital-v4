# CDA Digital V4 - Portal Institucional Moderno

Portal institucional da **Câmara dos Despachantes Aduaneiros de Moçambique** - Versão 4.0

## 🎯 Objetivos da V4

- **Design Premium**: Identidade visual institucional moderna e chamativa
- **Redução de Densidade Textual**: Menos texto visível por tela, mas mesmo conteúdo disponível
- **Qualidade Visual**: Imagens de alta resolução, tipografia refinada, espaçamento generoso
- **Responsividade Sólida**: Experiência otimizada para todos os dispositivos
- **Funcionalidades Avançadas**: Verificação de profissionais, linha do tempo, centro documental

## 🎨 Sistema de Design

### Paleta de Cores
- **Azul Institucional**: `#0d1a26` (primário)
- **Azul Médio**: `#33587a` (secundário)
- **Vermelho CDA**: `#c01818` (destaque)
- **Neutro Claro**: `#faf8f5` (fundo)
- **Neutro Médio**: `#e4ddd2` (bordas)
- **Branco**: `#ffffff`
- **Preto**: `#000000`

### Tipografia
- **Títulos (Serif)**: Gellix (ou Playfair Display)
- **Corpo (Sans-Serif)**: Manrope (ou Inter)
- **Interface**: Manrope

### Breakpoints
- Mobile: 400px
- Tablet: 760px
- Desktop: 1000px
- Large: 1240px

## ✨ Funcionalidades Principais

### 1. Verificação de Despachantes
- Pesquisa por código profissional, nome ou cédula
- Resultado com status de registo
- QR Code para verificação rápida

### 2. Linha do Tempo
- História da CDA desde 1996
- Eventos interativos com documentos relacionados
- Fotografias históricas

### 3. Centro Documental
- Legislação, circulares, regulamentos
- Pesquisa avançada
- Categorização por tipo

### 4. Verificação de Empresas
- Pesquisa por nome ou código
- Ligação a despachantes registados

### 5. Denúncia de Fraude
- Formulário de comunicação de suspeitas
- Encaminhamento institucional
